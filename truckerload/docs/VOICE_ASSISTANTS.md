# Голосовой ассистент (Google Assistant / Gemini)

Команды — это **экраны и действия TruckoRig**, не абстрактный каталог.

Ассистент понимает те же подписи, что на вкладках и в меню.

## Экраны (как в приложении)

| Сказать (как на кнопке) | Экран |
|---|---|
| Грузы / Loads | Журнал |
| Добавить груз / Add load | Форма нового груза |
| Цель / Goal | Недельная цель |
| Отчёты / Reports | Аналитика |
| Карта / Map | RPM по штатам |
| Профиль / Настройки | Профиль / настройки |
| Документы | Галерея сканов |
| Галерея фото | Фото |
| ТО / Maintenance | Обслуживание |
| Добавить зарплату / дизель | Соответствующие формы |
| Сканер / Камера | Сканер / камера |
| Финансовый советник | Советник |
| О приложении | About |

Примеры:

- «Ok Google, open TruckoRig добавить груз»
- «Ok Google, TruckoRig цель недели»
- «Ok Google, TruckoRig карта»

iOS / Siri: отдельного клиента нет. Когда появится, те же `Routes` вешаются на App Intents один-к-одному.

Deep links: `truckerload://app/add_load`, `truckerload://assistant/open?featureName=цель`.
