# Голосовой ассистент (Google Assistant / Gemini)

Команды — это **экраны и действия Truck Log**, не абстрактный каталог.

Ассистент понимает те же подписи, что на вкладках, в меню и в сообществе.

| Сказать (как на кнопке) | Экран |
|---|---|
| Грузы / Loads | Журнал |
| Добавить груз / Add load | Форма нового груза |
| Цель / Goal | Недельная цель |
| Отчёты / Reports | Аналитика |
| Карта / Map | RPM по штатам |
| Друзья на карте / Friends live | Живая карта друзей |

| Профиль / Настройки | Профиль / настройки |

| Галерея фото | Фото |
| ТО / Maintenance | Обслуживание |
| Добавить зарплату / дизель | Соответствующие формы |
| Сканер / Камера | Сканер / камера |
| Голосовые комнаты | Voice rooms |
| Статусы / Группы | Статусы / группы |

| О приложении | About |

## Действия с друзьями (как в чатах)

| Сказать | Что сделает |
|---|---|
| чат с @ник | Откроет личный чат |
| напиши @ник текст | Откроет чат и подставит текст. **Отправка только после кнопки** |
| позвони @ник | Звонок **после подтверждения** на экране |

Примеры:

- «Ok Google, open Truck Log добавить груз»
- «Ok Google, Truck Log чат с Nick»
- «Ok Google, Truck Log друзья на карте»

Незнакомый ник открывает Сообщество, чтобы друга можно было добавить там.

iOS / Siri: отдельного клиента нет. Когда появится, те же `Routes` вешаются на App Intents один-к-одному.

Deep links: `truckerload://app/add_load`, `truckerload://assistant/chat?peer=Nick`.
